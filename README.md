# Volunteer Management Information System

## Жоба туралы

Бұл жоба волонтерлерді басқару және оларды іс-шараларға автоматты түрде бөлу ақпараттық жүйесін әзірлеуге арналған.

## Жобаның мақсаты

Волонтерлерді тіркеу, іс-шараларды ұйымдастыру, өтініштерді қабылдау және волонтерлерге сәйкес іс-шараларды ұсыну.

## Негізгі мүмкіндіктер

- Волонтерлерді тіркеу және басқару
- Іс-шараларды құру
- Іс-шараларға өтініш беру
- Волонтерлерге іс-шаралар ұсыну
- Өтініш мәртебесін бақылау
- Хабарламалар жіберу

## Қолданылатын технологиялар

- SQL Server
- Visual Studio Code
- Git
- GitHub

## Деректер базасы

Жүйеде 6 негізгі кесте бар:

1. Volunteer
2. Organizer
3. Event
4. Application
5. Recommendation
6. Notification

## Жоба құрылымы

- `database/create_tables.sql` — кестелерді құру
- `database/insert_data.sql` — мәліметтер енгізу
- `database/update_delete.sql` — мәліметтерді өзгерту және өшіру
