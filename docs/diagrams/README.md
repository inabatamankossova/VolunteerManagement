# UML диаграммалары

Бұл папкада «Волонтерлерді басқару және іс-шараларға автоматты бөлу ақпараттық жүйесі» жобасының диаграммалары сақталады.

Жоба үшін дайындалатын диаграммалар:

- Use Case Diagram
- Activity Diagram
- Sequence Diagram
- Class Diagram

Диаграммалар жүйенің құрылымын, пайдаланушылардың әрекеттерін және негізгі процестерін сипаттайды.
