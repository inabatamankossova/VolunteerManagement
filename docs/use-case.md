# Use Case — Волонтерлерді басқару ақпараттық жүйесі

## 1. Жүйенің негізгі қатысушылары (Actors)

Жүйеде үш негізгі пайдаланушы бар:

- **Волонтер (Volunteer)**
- **Іс-шара ұйымдастырушысы (Organizer)**
- **Әкімші (Admin)**

## 2. Волонтердің әрекеттері

1. Жүйеге тіркелу және кіру.
2. Жеке профилін толтыру.
3. Дағдылары мен қызығушылықтарын енгізу.
4. Бос уақытын көрсету.
5. Іс-шараларды қарау.
6. Сәйкес іс-шаралар бойынша ұсыныстар алу.
7. Іс-шараға өтініш беру.
8. Өтініш нәтижесін қарау.
9. Қатысу тарихын көру.

## 3. Ұйымдастырушының әрекеттері

1. Жүйеге кіру.
2. Жаңа іс-шара құру.
3. Іс-шара туралы ақпаратты өзгерту.
4. Волонтерлердің өтініштерін қарау.
5. Өтінішті қабылдау немесе қабылдамау.
6. Қатысуды тіркеу.

## 4. Әкімшінің әрекеттері

1. Пайдаланушыларды басқару.
2. Іс-шараларды бақылау және басқару.
3. Жүйедегі мәліметтердің дұрыстығын қадағалау.

## 5. Негізгі Use Case: Іс-шараға өтініш беру

**Actor:** Волонтер

**Мақсаты:** Таңдалған іс-шараға қатысуға өтініш жіберу.

**Алдын ала шарт:** Волонтер жүйеге кірген.

**Негізгі сценарий:**

1. Волонтер іс-шаралар тізімін ашады.
2. Өзіне сәйкес іс-шараны таңдайды.
3. Іс-шара туралы ақпаратты қарайды.
4. «Өтініш беру» батырмасын басады.
5. Жүйе өтінішті тіркейді.
6. Өтініш мәртебесі `Pending` болады.
7. Ұйымдастырушы өтінішті қарайды.
8. Ұйымдастырушы өтінішті қабылдайды немесе қабылдамайды.
9. Волонтер өтініш нәтижесі туралы хабарлама алады.

**Нәтиже:** Өтініш жүйеде сақталады және оның мәртебесі көрсетіледі.

## 6. Қорытынды

Use Case сипаттамасы волонтер, ұйымдастырушы және әкімшінің жүйемен өзара әрекеттесуін көрсетеді.
